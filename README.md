# TickWork — téléchargements

Timer Windows local-first. **Pas de source ici** — uniquement les installs.

## Télécharger

Va dans [Releases](https://github.com/Ijipop/TickWork-Releases/releases) et prends :

- **TickWork_x.y.z_x64-setup.exe** — installeur (WebView2 inclus, pas d’admin)
- **zip portable** — dézippe, ajoute un fichier `portable.txt` à côté de l’exe si tu veux garder les données dans le dossier

## Langues

Français et English (langue Windows, ou choix dans les réglages).

Le code source est privé. Les mises à jour de l’app pointent vers ce dépôt.
